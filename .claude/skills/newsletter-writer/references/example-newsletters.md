# Gold example newsletters (user-validated)

These are finished newsletters Bjion has personally confirmed read accurately in
his voice. Treat them as the target. When in doubt about tone, cadence, or how
much of his process detail to keep, match these rather than guessing.

Each entry shows the source post and the converted newsletter so you can see the
transform: what gets kept, what gets cut (CTAs, transcript errors, hype), and how
the William structure is applied without any personal story.

---

## Example 1 — "How we launch a campaign inside Claude Code"

**Why it's a gold example:** it's a process-walkthrough playbook (real value, no
hot-take), built from ONE source, with his exact `→` arrow list, two-beat opener
("Every step, one place."), specific numbers kept (three providers, 17,000
prospects), tool names corrected from the transcript (Claude Code not "Cloud
Code", AI Ark not "AIARC", Prospeo not "Prospio", Navreo not "Navrium"), the
book-a-call CTA and the "Anyone else doing the same?" engagement bait both
dropped (pure value), no em-dashes, and a plain practitioner closer rather than a
manicured maxim.

**Source (LinkedIn post + Loom walkthrough):** Bjion walks through launching a
campaign end to end inside Claude Code: TAM mapping across Ocean / AI Ark /
Prospeo at once into one deduped list; decision-maker finding with an
auto-updating exclusion list so the same contact is never paid for twice; email
verification via MillionVerifier (proactive or retrospective, across every
campaign); copywriting around set angles/templates with auto-suggested new
variants in his style; upload straight into Smartlead with changes pushed across
every campaign at once; the icebreaker added LAST so Claude writes it with the
full context (brief, companies, job openings, tech stack), not just name + title,
run across 17,000 prospects; then a QA pass on every variable before go-live.
"No Clay. No tool-switching. No copy-pasting between tools."

**Converted newsletter:**

> **Subject:** How we launch a full campaign without leaving Claude Code
> **Preview:** (every step, one place)
>
> Hey %FIRSTNAME%,
>
> We launch entire campaigns now without ever leaving Claude Code. Every step, one place.
>
> It used to be a relay race. Pull a list in Ocean, cross-check AI Ark, dedupe against Prospeo, export, re-import, bounce to the next tool. Every handoff was a chance to lose data or burn an hour.
>
> Here's the whole process now, start to finish:
>
> → TAM mapping across all three providers at once, pulled into one deduped list
> → decision-maker finding with an auto-updating exclusion list, so we never pay for the same contact twice
> → email verification through MillionVerifier, run across every campaign at once, proactively or after the fact if bounces creep up
> → copywriting around our angles and templates, and when a variant's winning, Claude drafts the next one in the same style on its own
> → upload straight into Smartlead, with any change pushed across every campaign instantly
> → a QA pass on every variable before anything goes live, to catch the silly mistakes a human skims past
>
> The part I'd point to, %FIRSTNAME%, is where the icebreaker sits. It goes in last, on purpose.
>
> By that point Claude already has the brief, the companies, the job openings and the tech stack. So it writes the opener with all of it, not just a name and a job title. On the last build we ran that across 17,000 prospects, and it still handed back a breakdown of which angles it actually used.
>
> No Clay. No tool-switching. No copy-pasting a list between five tabs.
>
> The whole launch is faster now, and nothing falls through the gaps between tools.
>
> Bjion

**Transform notes (apply these patterns generally):**
- A noisy auto-transcript is fair source material. Fix the obvious speech-to-text
  errors (names, tools) before writing. Never let a transcription artefact reach
  the newsletter.
- Keep the genuinely useful, slightly non-obvious detail as the standout (here:
  the icebreaker goes LAST so it writes with full context). That one detail is
  what makes it worth reading versus a generic "we use AI" post.
- Drop every CTA and engagement-bait line ("book a call", "Anyone else doing the
  same?"). The newsletter is pure value.
