## Notes on the table
- **Reach scale** is a rough knowledge-based band (Small <5K · Mid 5–30K · Large 30–100K · Very large 100K+), NOT a verified follower count. Confirm exact follower counts + the correct LinkedIn company page at scrape time via `lilly-linkedin-page-finder`.
- "Filter hard" flags = broad companies (Tag, Keywords, TransPerfect) whose follower base is mostly off-target; they're worth scraping only because the absolute number of on-title followers is still large, but title-filtering must be strict.

## Hand-off chain (on shortlist sign-off)
1. `lilly-linkedin-page-finder` — resolve the exact LinkedIn company page for each approved competitor.
2. `lilly-company-followers` — scrape followers per page.
3. Filter scraped followers by Gary's target titles (the ~100-title list + A/B/C scoring he's sending).
4. Verify/enrich emails (`lilly-email-verification`) → Smartlead; no-email leads → Lemlist.
