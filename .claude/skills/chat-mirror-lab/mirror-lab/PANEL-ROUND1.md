## Verdict — no pass yet. Fix list for round 2

1. **Shared** - a run change that moves a number flags it: the headline and rail number flash
   once when chat's update lands (Dana/Fiona; the biggest actionable-insights miss).
2. **M1** - the ribbon stays while a session is live (replaced by the next note), instead of
   fading to nothing between steps (Marcus/Tunde).
3. **M2** - each rail entry gets a small mono time; visible cards capped at 4 with the older
   ones fading harder (Dana/Tunde); catch-up chip gets the orange dot treatment (Renee).
4. **M3** - checks/sign-off spotlight targets the step heading, not the button row (Fiona/
   Tunde); pure view moves (no data change) sweep WITHOUT auto-scroll - scroll only when a
   concrete element changed (Dana/Renee).
